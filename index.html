01

Beacon · LFG for co-op games

A live looking-for-group site for co-op games that ship without matchmaking. Games like Peak are great with four people and unplayable alone, and the existing answer is a scattered pile of Discord LFG channels that are noisy and impossible to filter. Beacon is one place to post "need 2 for Peak, starting now" and actually get them.

Hosts post a group against a live search over 200,000+ titles with real cover art, then approve or deny applicants individually. Groups fill and reopen on their own as players come and go. Discord invites and lobby codes stay hidden until someone is accepted. There's a separate set of tools for streamers running viewer games: link-only groups, first-come auto-fill, random picks, and round rotation.

The parts I'm most happy with are underneath. Every access rule lives in Postgres row-level security rather than in the front end, so "only the host can approve" and "only accepted players see the invite" hold even if someone talks to the API directly. Approvals lock the group row, so two people accepted in the same instant can't overfill a lobby. Steam linking goes through OpenID and is verified server-side so accounts can't be spoofed. The slur filter runs in the database and normalizes leetspeak, spacing, and repeated letters before it matches, with the term list stored encoded so it isn't readable from the client.

Built and shipped solo, start to finish: schema design, security policies, OAuth, third-party APIs, real-time, UI, and production deploy. Getting the first users through the door turned out to be the harder half.

02

10" 6U Homelab Rack

A 6U ten-inch server rack designed from scratch in Blender and printed on a Bambu X2D. It's built around two pairs of Gator Rackworks heavy-duty steel rails, so every module lands on real 10-32 rack threads rather than printed ones. Each 1U module is independent — base and top frame with slot grille, a dual mount carrying a Raspberry Pi 5 and 4B side by side, switch shelf, PDU, 12-port patch panel, fan rack, and blanks — so the layout can be rearranged or reprinted a piece at a time.

Most of the real work was in the constraints. The side panels are two layers, a 3mm inner panel and a 1.6mm outer cover, split into halves so every piece fits a 256mm bed; the cover pieces are mirrored before slicing so the textured PEI face ends up on the outside where it's visible. The slot cutouts in the rear and top panels are spaced to match a 120mm fan's bolt pattern, so additional fans drop straight in without drilling. The Pi 5 mount is raised to clear an NVMe HAT underneath and a tower cooler on top.

Two parts are modified from other creators and credited on the model page: the TL-SG108E switch rack and the 4.3" display mount.

03

Self-Hosted Network Stack

The two Pis in that rack run DNS and remote access for the whole apartment. Pi-hole v6 handles filtering, with Unbound behind it as a local recursive resolver so lookups resolve from the root servers instead of going out to a third-party upstream. Tailscale provides access from outside the LAN, which matters here because the unit is on GPON fiber with no gateway admin access — no port forwarding and no DHCP reservations available from the router side, so every piece has to work without them.

A small Flask service exposes live host metrics over the LAN, managed by systemd so it survives reboots. The Pi 4B polls that endpoint and renders the stats on a 4.3" DSI panel mounted in the rack, with a long-press gesture to switch the display into music mode.

04

Spotify Desk Companion

A standalone desk device that shows what's playing, scrolls synced lyrics, and renders a live audio visualizer. A Raspberry Pi 4B with a touchscreen runs a pygame UI with invisible touch zones for transport controls. A companion Windows app captures system audio over WASAPI loopback, runs an FFT, and streams the spectrum plus BPM and loudness to the Pi over UDP in real time. Track data comes from the Spotify Web API with rate-limit-aware polling and a fast-poll window for snappy skips.
